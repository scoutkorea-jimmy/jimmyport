**작업 중 실제로 잡은 버그 3건**(전부 회귀에 고정)
1. **`[hidden]` 이 무력화돼 목차 패널이 화면을 덮고 클릭을 가로챔** — `.toc{display:flex}`(클래스 선택자)가 UA 의 `[hidden]{display:none}` 을 이긴다. 상단바·넘김 버튼 클릭이 전부 썸네일로 들어가 엉뚱한 쪽으로 점프했다. → 전역 `[hidden]{display:none!important}` + `#leafUnder`·`#leafFlip` 에 초기 `hidden` 속성.
2. **썸네일이 세로로 늘어나 좌우가 잘림** — `img` 의 `height="180"` 속성이 살아 있고 CSS 가 `width` 만 지정하면 **양쪽이 확정되어 `aspect-ratio` 가 무시된다**. → `.tocitem img{height:auto}`.
3. **가로 보기 확대 효과가 반감** — `.book` 이 flex 아이템이라 기본 `flex-shrink:1` 로 지정 폭이 스테이지 폭까지 눌렸다(회전 전 기준 축소). → `.book{flex:none}`.

### 19.4 v0.9.237 — 모바일 '이어보기'(세로 스크롤) 모드

**사용자 지시**: "모바일에서 봤을때에는 내용을 직접 클릭해서 넘기는형식도 좋지만, 슬라이드로 위아래 할 수 있는 건 어때?"
**확정**(AskUserQuestion): **문서처럼 죽 이어보기**(스냅 없는 연속 스크롤) · **모바일·터치에만** 적용(PC 는 책장 넘기기 유지).

- **피드**(`#feed`): 31쪽을 세로로 쌓고 쪽마다 `번호 + 제목` 캡션. 이미지 `loading="lazy"` + 1920×1080 속성으로 자리 예약. 최대 폭 900px(태블릿).
- **현재 쪽 판정**: 스크롤 시 rAF 로 **상단 기준선(위에서 min(64px, 25%))에 걸린 첫 쪽**을 현재 쪽으로. 하단 표시·스크러버·목차 강조·해시가 그대로 연동된다.
  - ⚠️ 처음엔 '화면 중앙' 기준으로 짰다가 실패 — 세로 화면엔 한 번에 3쪽 가까이 보여서, 목차로 20쪽을 열면 중앙엔 21~22쪽이 걸려 **현재 쪽이 곧바로 튀었다**. 문서 뷰어 관습대로 상단 기준으로 바꿔 해결.
  - ⚠️ `el.offsetTop` 은 `offsetParent` 가 무엇이냐에 따라 기준이 달라져 스크롤 위치가 어긋났다(`.feed` 에 `position:relative` 가 없었음). **스크롤 컨테이너 기준 좌표는 rect 차이로 계산**(`feedTopOf`) + `.feed{position:relative}`.
- **확대**: 커스텀 줌 대신 **브라우저 기본 핀치줌**에 맡긴다(`.stage` 와 달리 `touch-action` 을 막지 않음). 이어보기 중엔 '가로 보기' 버튼을 숨긴다.
- **모드 전환**: 하단 바 우측 버튼(터치 기기에만 노출)으로 `이어보기 ↔ 한 장씩(플립북)`. 보던 쪽을 유지하고 `localStorage: krjam-fnc:mode` 에 기억. 터치 기본값은 이어보기.
- 목차·스크러버·키보드·딥링크는 두 모드에서 동일하게 동작(이어보기에선 해당 쪽으로 스크롤).

**검증**: 회귀 **82/82 통과**(67 → 82). 추가: 터치 기본 모드 · 세로 배치/스크롤 가능 · 캡션 · 스크롤→현재 쪽/해시 갱신 · 목차/스크러버로 스크롤 이동 · `touch-action` 미차단 · 모드 전환 시 쪽 유지/저장 · PC 는 피드·모드버튼 숨김.

### 19.5 v0.9.239 — 진입 연출 · 살아있는 배경 · 로딩 표시

**사용자 지시**: "홈페이지에 조금 화려한 애니메이션들을 줄 수 있나?" + "로딩중이면 로딩중인 중간 로딩 바라던지 이런것들을 포함해서".

> [ui-ux.md](../../rules/ui-ux.md) 의 '절제' 원칙과 긴장이 있는 선택이라 질문에 그 점을 적어 확인받았다. 구현은 **느리고 은은하게**(20~44초 주기), 색은 기존 브랜드 팔레트 안에서, `prefers-reduced-motion` 이면 전부 정지.

**`/krjam-fnc`**
- **부팅 로딩 화면**: 엠블럼(맥박) + **진행바** + 문구. 실제로 기다리는 것에 맞춰 단계를 올린다 — 시작 22% → 글꼴 준비(`document.fonts.ready`) 55% → 첫 장 이미지 100%. 그 사이엔 90%까지 천천히 기어가 멈춰 보이지 않게. 4초 안전 타임아웃.
  - 엠블럼(117KB)이 늦게 오면 로딩 화면이 비어 보여 `<link rel=preload fetchpriority=high>` + 원형 플레이스홀더 배경.
- **넘김 진행바**(`#topload`): 다음 장이 캐시에 없을 때만. 캐시된 넘김에서 깜빡이지 않도록 **120ms 지연 후** 켜고 도착 즉시 끈다.
- **이어보기 스켈레톤**: 아직 안 내려온 쪽은 16:9 자리에 시머가 흐르고(캡션은 먼저 보인다), 도착하면 그 자리에서 이미지가 페이드인.
- **배경**: 스테이지 뒤에 아주 느린 두 겹(30s·38s). 이어보기(피드가 화면을 덮음)에서는 `display:none` 으로 아예 끈다.
- **진입**: 상단바 → 목차 → 본문 → 하단바 순차 등장.
  - ⚠️ **`.book` 은 opacity 만 애니메이션한다.** `transform` 을 넣었더니 `animation-fill-mode:both` 가 끝난 뒤에도 그 값이 남아 **'가로 보기'의 `rotate(90deg)` 를 덮어써서** 회전이 죽었다(회귀가 잡음).

**`/` 랜딩**
